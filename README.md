# Nitro Sports Academy Website

A modern, multi-page website for Nitro Sports Academy — a premier baseball and softball training facility.

## Pages
- **Home** — Hero, features, facility highlight, membership preview, CTA
- **History** — Timeline, mission & values
- **Our Team** — Coach profiles
- **Lessons** — All training programs offered
- **Membership** — Pricing cards + FAQ accordion
- **Contact Us** — Contact form + hours + map embed

## Colors (from logo)
- **Royal Blue:** `#2B4FA8`
- **Silver/Gray:** `#9AA0B4`
- **Gold accent:** `#E8B84B`
- **Dark background:** `#0D1321`

## Tech Stack
- Pure HTML, CSS, JavaScript — no frameworks or build tools needed
- Google Fonts: Oswald (display) + Barlow Condensed + Barlow (body)
- Fully responsive (mobile, tablet, desktop)

## How to Use
1. Open `index.html` in any browser
2. No build step required — it just works!
3. To deploy: upload the entire folder to any static host (Netlify, GitHub Pages, Vercel, etc.)

## Customization
- Update coach names/bios in the `#team` section of `index.html`
- Update hours in the `#contact` section
- Add the real address once available
- Replace the map embed with an accurate Google Maps URL
- Add real staff photos by replacing the emoji placeholders with `<img>` tags

## Deploying to GitHub Pages
1. Create a new GitHub repo (e.g., `nitro-sports-academy`)
2. Upload all files preserving the folder structure
3. Go to Settings → Pages → Source: main branch / root
4. Your site will be live at `https://yourusername.github.io/nitro-sports-academy`
